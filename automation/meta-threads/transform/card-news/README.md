# 카드뉴스 변환·제작

Threads 원문을 바탕으로 `content/card-news/template.md` 기준에 맞춰 **4~6장 분량의 설명 문안**을 만든다.

변환기는 원문의 단락을 순서대로 각 장에 한 번씩 배분한 `card-plan.json`과 `image-prompts.md`를 만든다. 이 문안은 ChatGPT 이미지 생성에 장별로 전달해 Instagram 피드용 **4:5 카드 이미지**로 제작한다. 고정 템플릿 렌더링으로 이미지를 찍어내지 않는다. 장별 문안과 생성 이미지는 한 콘텐츠 폴더에 함께 보관하고, 한글 표기·사실·출처·비율을 확인한 뒤 검수 대기 상태로 둔다.

활용 예시를 그릴 때는 실제 제품 화면이나 실행 결과와 분명히 구분한다. 실사 본인 사진은 카드뉴스 생성에 전달하지 않는다. 캐릭터는 필요한 경우에만 투명 배경 컷아웃을 사용하며, 캐릭터 디자인을 임의로 다시 그리지 않는다.
