## 제작 원칙

- 컷 구성, 길이, 시각자료, 목소리, 음악은 게시물 주제와 원문에 맞춰 정한다. 한 편의 형식을 다음 주제의 기본 템플릿으로 복제하지 않는다.
- 본인 사진·얼굴은 릴스에서만 쓰며, 사용할 때도 얼굴을 변형하지 않는다. 말하지 않는 정지 사진을 장식으로 넣지 않는다. 손 사진과 인물 PIP를 기본값으로 쓰지 않는다.
- 카드뉴스는 별도 형식이며 4~6장으로 만든다. 카드에 실사 얼굴을 넣지 않고, 캐릭터는 필요할 때 하나만 선택해 쓴다.
- 타자음·ASMR·음악을 고정 기본값으로 두지 않는다. 실제 영상의 리듬과 게시 목적에 맞춰 소리를 정하고 청취 확인한다.
- 최종 영상은 9:16 세로 MP4로 만들고, 검수 전 자동 게시하지 않는다.
- 참고 게시물은 첨부 이미지의 룩을 그대로 따기보다 게시글 본문과 생성 프롬프트의 제작 의도를 먼저 읽는다. 공식 자료 조사·짧은 러닝타임·의미 있는 모션·리듬 전환을 해당 주제에 맞게 옮긴다.
- 보라색 글로우·반복 그리드·유리 패널·떠다니는 카드로 'AI 느낌'을 자동 연출하지 않는다. 배경을 깨끗하게 두고 주제에 필요한 자료와 강조색만 남긴다.
- API 데모에 실제 결과값을 쓸 경우 실제 호출 응답을 사용한다. 문서의 `Example Value`나 로컬 목업은 라이브 응답처럼 보이게 하지 말고 화면에 `공식 문서 예시` 또는 `설명용 예시`를 표시한다.
- 화면은 밝고 읽기 쉽게 유지하되, 파랑·연두 패널이나 생성 앱 화면을 고정 템플릿으로 쓰지 않는다. 설명형 글은 사용자 원문 문장을 먼저 배치하고, 실제 자료가 있을 때만 출처를 붙여 보여준다. 생성 그림이 필요한 경우에만 실제 UI와 구별해 사용한다.
- 영상의 글자·선·패널은 9:16 안전 영역 안에서 경계를 검사하고, 인코딩 결과를 프레임 샘플과 재생으로 다시 확인한다.
