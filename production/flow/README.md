# Google Flow

Flow에서 생성한 세로 영상 소재와 생성 메모를 두는 위치입니다. 현재 원본 클립은 Flow 프로젝트에서 관리되고 있으며, 이 폴더에는 로컬 원본을 아직 복사하지 않았습니다.

## 실사 본인 사용 규칙

- `content/character/reel-human-reference/`의 사진은 릴스 제작에만 참조한다.
- 얼굴형·눈·코·입·피부 톤·헤어라인·나이 인상을 변형하지 않는다.
- 얼굴을 다른 사람처럼 바꾸는 스타일 변환, 과한 보정, 캐릭터화는 금지한다.
- 카드뉴스 제작에는 이 사진이나 본인 얼굴 레퍼런스를 사용하지 않는다.
