# @stockai 카드뉴스 제작 기준

## 출력 규칙

- 카드 수는 **4~6장** 중 하나로 정한다. 기본은 5장이며, 정보량에 따라 4장 또는 6장으로 조정한다.
- 인스타그램 피드용 세로 **4:5 비율**로 모든 장을 통일한다. 목표 규격은 1080×1350이며, 같은 4:5 비율이면 생성 이미지의 원본 픽셀 크기는 달라도 된다.
- 카드 이미지는 ChatGPT 이미지 생성으로 만든다. 고정 템플릿에 긴 문장만 주입해 모든 장을 복제하지 않는다.
- 이미지 프롬프트 전에 카드별 핵심 문장과 설명 문안을 먼저 확정한다. 생성 이미지의 한글 문구와 사실관계를 장마다 확인한다.
- 표지에만 표지 수준의 큰 제목을 허용한다. 본문은 설명 문장·도식·사례·비교표 등 주제에 맞춰 레이아웃을 바꾸고, 제목만 있는 장을 반복하지 않는다.
- 본문에는 독자가 맥락을 이해할 만큼의 설명을 담되, 휴대폰에서 읽히지 않을 정도로 글자를 줄이지 않는다.
- 원문에 없는 수치·예측·성과·사용 후기를 만들지 않는다. 변동 가능한 가격·접근 조건은 발행 시점의 공식 안내를 확인하기 전에는 이미지에 넣지 않는다.
- 활용 흐름을 그린 경우 실제 제품 화면이나 실행 결과처럼 오해되지 않도록 예시임을 표시한다.
- 사람형 캐릭터 또는 뿔 달린 뱀 캐릭터는 장면에 필요할 때만 사용한다. 둘 다 매장에 넣지 않으며, 원본 실루엣을 임의로 바꾸지 않는다.
- 실사 본인 사진은 카드뉴스에 넣지 않는다. 릴스에서만 사용하며 얼굴 변형을 금지한다.
- 마지막 장에는 결론과 출처를 넣는다.

## 기본 5장 흐름

1. **표지:** 질문 또는 핵심 주장 + 주제가 무엇인지 알려주는 짧은 설명.
2. **개념:** 용어·역할·기존 방식과의 차이를 쉬운 말로 설명.
3. **예시:** 상황에서 결과까지 순서를 보여준다. 가상 사례는 가상이라고 표시.
4. **경계와 작동 방식:** 누가 판단하고 누가 실행하는지, 오해하기 쉬운 한계를 설명.
5. **활용·요약·출처:** 언제 검토할지와 핵심 한 줄, 공식 자료를 정리.

이 흐름은 출발점일 뿐 고정 서사가 아니다. 주제와 원문의 정보 구조에 맞게 바꾼다.

## 결과물 폴더

콘텐츠마다 다음 자료를 한 폴더에 모은다.

- `01-cover.png` … `05-summary.png` — 인스타그램 4:5 카드 이미지
- `card-copy.md` — 카드별 설명 문안
- `caption.txt` — 게시물 설명과 링크
- `review.md` — 사실·출처·비율·문구 검수 기록
- `README.md` — 장 구성과 최종 파일 안내

카드 이미지를 생성했다고 자동 게시하지 않는다. 최종 이미지는 검수 후 사용한다.
