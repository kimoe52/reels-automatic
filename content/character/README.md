# 캐릭터 레퍼런스

사람형 캐릭터와 뿔 달린 뱀 중 콘텐츠에 필요한 쪽만 선택한다. 두 캐릭터를 모든 카드·영상에 함께 넣지 않는다. 라벤더 배경은 원본 이미지의 배경일 뿐, 고정 색상이 아니다.

## 사람형 캐릭터

- 원본: [character-human.png](./character-human.png)
- 투명 배경 컷아웃: [character-human-cutout.png](./character-human-cutout.png)
- 흑발, 흰 얼굴·상의, 검은 선화, 초록 오이 소품을 기준으로 한다.
- 정확한 캐릭터가 필요하면 컷아웃 파일을 우선 사용하고 얼굴·헤어·의상·실루엣을 임의로 바꾸지 않는다.

## 뿔 달린 뱀

- 원본: [character-creature.png](./character-creature.png)
- 투명 배경 컷아웃: [character-creature-cutout.png](./character-creature-cutout.png)
- 둥근 흰 몸, 짧은 검은 뿔, 작은 눈, 초록 오이를 문 실루엣을 유지한다.
