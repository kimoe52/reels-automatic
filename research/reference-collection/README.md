# 레퍼런스 수집·검수 기준

조사일: 2026-09-23 (KST)

이 폴더는 인스타그램 공개 검색에서 수집한 **릴스 후보**와 **카드뉴스 후보**를 분리해 보관한다. 최초 후보 수집은 각 100개 안팎이었지만, 실제 검수 목표는 사용자가 요청한 대로 **릴스 30개와 카드뉴스 30개**다.

## 숫자 해석

- `discovered`: 검색 결과에서 게시물 URL을 확인한 후보. 아직 게시물 본문·좋아요·슬라이드 수를 모두 검증한 것은 아니다.
- `verified`: 게시물 페이지를 직접 열어 형식과 공개 반응 수를 확인한 항목.
- 검색 후보 100개를 곧바로 “인기 100개”라고 부르지 않는다. 인기 여부는 공개 좋아요·조회수 또는 별도 플랫폼 자료로 확인된 경우에만 기록한다.

## 후보 수집과 실제 검수의 구분

- 릴스 후보: `reference-candidates-2026-09-23.json`의 `reels` 배열
- 카드뉴스 후보: 같은 파일의 `carousels` 배열
- 직접 확인한 릴스: 기존 4개 + 이번 배치 10개
- 직접 확인한 카드뉴스/슬라이드: 이번 배치 10개
- 공개 반응을 확인한 대표 샘플은 `verified-samples-2026-09-23.md`에 따로 기록한다.
- 실제 시청·슬라이드 완독 진척은 각각 `reel-watch-log-2026-09-24.md`, `carousel-watch-log-2026-09-24.md`에서 확인한다. 후보 URL 개수나 좋아요만 확인한 개수는 완독 수로 계산하지 않는다.

## 주의

인스타그램 검색 결과는 로그인 상태, 지역, 시점에 따라 순서와 노출 항목이 달라질 수 있다. 이 자료는 제작 방향을 잡기 위한 편집 레퍼런스이며, 다른 계정의 영상·이미지를 재업로드하기 위한 자료가 아니다.
