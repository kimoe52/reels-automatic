## 카드뉴스 패턴

- 커버: `Jev가 뭐예요?`보다 실패·손실·선택을 먼저 보여준다.
- 2~3장: 정의보다 핵심 선택지와 적용 예시를 먼저 준다.
- 4~6장: 한 장에 한 메시지만 둔다. 이번 제작 기본값은 5장이다.
- 마지막 장: 새 정보가 아니라 저장용 요약과 CTA 한 개만 둔다.
- `DbYspcsGryX`는 직접 확인한 다중 슬라이드 후보이며, 본문 좋아요가 약 2.3만으로 표시됐다. 댓글 좋아요(예: 519)와 섞지 않았다.
- 카드 후보 중 낮은 반응 항목도 남겨 둔다. 잘된 카드만 모으면 실패한 커버·과밀한 첫 장을 비교할 수 없다.

## 이번 프로젝트에 적용할 편집 결정

### 릴스

1. 0~1초: `BUILD FAILED` 또는 결과 화면 + `다음에 뭘 하지?`
2. 1~4초: 재시도 / 다른 AI / 다른 툴 / 사람 확인 네 선택지
3. 4~6초: 사용자의 원본 얼굴 리액션 1~2초. 얼굴 변형·립싱크·미용 보정 없음
4. 6~20초: 상황 입력 → 판단 → 프로그램 실행을 실제 UI 또는 `예시 흐름`으로 표시
5. 20초 이후: 작업 AI와 판단 AI 비교, 저장 CTA

### 카드뉴스

1. 문제/오픈 루프
2. 선택지 4개
3. Jev 정의
4. 입력→판단→실행 흐름
5. 저장용 요약

라벤더 배경은 고정하지 않는다. 카드의 주인공은 정보 구조이고, 뱀 캐릭터는 보조 기호로만 사용한다. 뿔은 오른쪽 캐릭터의 뱀 뿔로 유지한다.
