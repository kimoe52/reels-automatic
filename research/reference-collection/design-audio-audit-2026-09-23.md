# 디자인·오디오 재점검

2026-09-23에 Instagram 게시물을 브라우저에서 다시 열어 화면 구성과 오디오 표기를 확인했다. 좋아요·댓글 수는 확인 시점의 공개 수치이며, 브라우저에서는 릴스가 기본 음소거 상태였다. 따라서 아래 오디오 평가는 직접 청취한 음색 평가가 아니라, Instagram에 표시된 트랙명·영상 구조·자막을 기준으로 한다.

- 시각 문법: 실제 웹페이지·게시물 캡처를 화면 대부분에 사용하고, 보라색/검은색의 원본 화면 분위기를 살린다. 별도의 추상적인 카드 UI를 새로 그리지 않는다.

## 우리 v3와의 차이

v3의 어두운 그리드·네온 카드·둥근 패널은 정돈되어 있지만, 위 레퍼런스들이 사용하는 실제 화면 증거·사진 질감·큰 반응 자막이 없다. 그래서 ‘바이브코딩 릴스’라기보다 새로 만든 제품 소개 UI처럼 보인다. v3 릴스의 AAC 트랙도 기존 내레이션 파일을 붙인 시안이라, Jev 레퍼런스의 짧은 sped-up loop 오디오 문법과 맞지 않는다.

## 다음 제작에 적용할 사운드 규칙

1. Jev 릴스는 속삭임·ASMR 내레이션을 기본값으로 두지 않는다.
2. 1개의 짧은 루프형 인스트루멘털을 낮게 깔고, 화면 전환에 맞춰 클릭·키보드·알림·에러 한 번 정도만 추가한다.
3. 설명이 꼭 필요할 때만 짧은 음성 한두 문장을 넣고, 긴 AI 나레이션은 빼서 실제 화면과 자막이 먼저 읽히게 한다.
4. 오디오보다 첫 1초의 실제 Jev 화면, 짧은 한국어 반응 자막, 다음 증거 화면으로 넘어가는 컷 타이밍을 우선한다.
5. 카드뉴스는 무음 포맷이므로, 릴스용 루프와 효과음을 카드 이미지에 억지로 반영하지 않는다.
